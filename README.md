# Tutorial 5: Sensors and ML Inference

This repository contains two independent Android Studio demo projects.
Please open each folder as a separate project in Android Studio.

## LocationDemo
Starting point for the location exercises. Add the play-services dependencies from the tutorial slides before the first build.

## CameraDemo
Starting point for Camera Exercises 3–6 and on-device inference. The commented `// Exercise N: Uncomment below import statements` blocks mark what each exercise needs.

## Build setup

- IDE: Android Studio Quail 3 (or newer)
- Gradle 8.13, AGP 8.12.2, Kotlin 2.0.21
- compileSdk 36, targetSdk 36, minSdk 26
- Java / JVM: 21

Set Gradle JDK to 21 under Settings → Build, Execution, Deployment → Build Tools → Gradle.
